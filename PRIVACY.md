# Privacy Policy — PostPilot

PostPilot is a personal automation tool built and operated by Shayshank Rathore to draft, schedule, and publish posts to a single LinkedIn account on the owner's behalf. It is not distributed to or used by other end users.

## What data this app accesses

- **LinkedIn**: via LinkedIn's OAuth (`openid`, `profile`, `w_member_social` scopes), this app can read the connected member's basic profile identifier and publish posts to that member's LinkedIn feed. It does not read connections, messages, or any other member's data.
- **Anthropic (Claude API)**: post content is generated by sending prompts (recent post history, performance notes) to Anthropic's API to produce new draft text. No LinkedIn personal data beyond the connected account's own post history is sent.

## What is stored

- The LinkedIn OAuth access token (and refresh token, if issued) for the one connected account, stored in a private database on the app's hosting infrastructure.
- Post content, scheduling times, publish status, and engagement metrics (when manually entered) for posts made through this app.

## What is not done with this data

- Data is not sold, shared, or used for advertising.
- Data is not shared with any third party other than the API providers (LinkedIn, Anthropic) necessary to operate the app's own functionality.

## Data retention / deletion

Data is retained for as long as the app is in use. To disconnect the LinkedIn account and stop all posting, the owner can revoke the app's access from LinkedIn's own [Permitted Services](https://www.linkedin.com/psettings/permitted-services) settings at any time, which invalidates the stored token.
